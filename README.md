# Сап-Тигр

Пиксельная речная гонка в духе Денди/SNES. Герой в кепке на жёлтом сапе плывёт по извилистой реке через густой лес и уворачивается от камней, лесок и банок рыбаков, обгоняющих саперов, мостков для ныряния и плотин. По пути встречаются друзья на сапах: с пивом и собакой, с биглем, семья с тремя сыновьями.

## Как играть

Откройте `index.html` в браузере. Сборка и сервер не нужны.

| Клавиша | Действие |
| --- | --- |
| ← → | рулить |
| ↑ | грести сильнее |
| ↓ | притормозить |
| Enter / тап | старт, пропустить заставку |
| P | пауза |
| M | звук |

На телефоне снизу появляется экранный пад.

## Устройство

Вся игра в одном файле `index.html`: canvas 320×240, спрайты рисуются кодом при загрузке, звук через Web Audio. Шрифт Press Start 2P подгружается с Google Fonts, без интернета используется моноширинный запасной.
