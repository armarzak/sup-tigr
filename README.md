# Сап-Тигр

Пиксельная речная гонка с видом сверху в стиле General Chaos (Sega Genesis). Сап-Тигр в кепке плывёт на жёлтом сапе по извилистой реке через густой лес. На пути камни, брёвна, лески и банки рыбаков, низкие мосты, плотины, мостки для ныряния и обгоняющие саперы. Встречаются друзья на сапах: с пивом и корги, парень с девушкой и биглем, полная пара, семья с тремя сыновьями. С берега машут мама, папа и дочка.

**Играть:** https://armarzak.github.io/sup-tigr/

## Два режима

- **Сидя** — устойчиво, поворачивает быстрее. Только так можно проплыть под низким мостом.
- **Стоя** — быстрее, и можно прыгать: через брёвна, лески, плавающие банки и утят.

## Управление

| Клавиша | Действие |
| --- | --- |
| ← → | поворот |
| ↑ / ↓ | грести сильнее / тормоз |
| Shift или Z | встать / сесть |
| Пробел или X | прыжок (только стоя) |
| Enter / тап | старт, пропустить заставку |
| P | пауза |
| M | звук |

На телефоне снизу экранный пад: крестовина, A — прыжок, B — встать / сесть.

## Устройство

Вся игра в одном файле `index.html`, сборка не нужна. Canvas 320×240, река строится процедурно: прямые участки и повороты на 75–90°, камера едет за героем. Земля и лес рисуются кусками 128×128 и кешируются, спрайты рисуются кодом при загрузке, звук через Web Audio.
